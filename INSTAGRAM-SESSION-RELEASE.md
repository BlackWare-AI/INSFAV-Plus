Removed the explicit Test Session button and command. Session validity is still checked automatically during Instagram login and actual HD/download requests. Instagram Login now has Refresh and a selectable on-screen CookieManager Cookie Header, including HttpOnly values. Cookie text remains in the secure native screen and is never added to logs, diagnostics, exports or saved UI state.

Added a persistent Disable Thumbnail Fetcher switch. Disabling stops bulk requests, its foreground service, scheduled jobs, folder observer and download notifications while preserving the queue, images and both session methods. Enabling does not start or resume work. HD viewing and its existing 256×256 WebP write path keep using the Instagram session while bulk is disabled. Notifications are removed when work stops and are not recreated for idle queue status.

Foreground manual cookie paste, encrypted Save acknowledgement, mixed Netscape exports and HTTP Cookie headers remain supported. Persistent WebView remains the default. Package identities, signing certificates and data formats are preserved. Tests use synthetic cookies and offline fixtures; no live Instagram login or account success is claimed.
